# إعلان نُسك — Motion Graphics (Remotion)

إعلانٌ عموديّ مدّته 42 ثانية بدقّة 1080×1920 ومعدّل 30 إطارًا في الثانية، فكرته «رحلتك إلى الحرم تبدأ بخطوة… وخطوتك تبدأ مع نسك».

## التشغيل

```bash
npm install
npm run audio     # يولّد الموسيقى والمؤثرات في public/audio
npm run studio    # معاينة وتعديل حيّ في المتصفح
npm run render    # يُخرج out/nusuk-ad.mp4
```

يستعمل `remotion.config.ts` متصفّح Chromium المثبّت في بيئة السحابة، فإن شغّلت المشروع على جهازٍ آخر فاحذف سطر `setBrowserExecutable` ليُنزّل Remotion متصفّحه.

## البنية

| الملف | الوظيفة |
|---|---|
| `src/theme.ts` | الألوان والخطوط وجدول توقيت المشاهد |
| `src/scenes/S1Intro.tsx` | المشهد الأول: الكعبة ثلاثية الأبعاد تخرج من الضوء الذهبي |
| `src/scenes/S2App.tsx` | المشهد الثاني: خطوطٌ ذهبية، ثم الهاتف، ثم شاشة البداية والرئيسية |
| `src/scenes/S3Services.tsx` | المشهد الثالث: حجز العمرة، ثم الإقامة، ثم تنظيم الرحلة |
| `src/scenes/S4Prizes.tsx` | المشهد الرابع: صندوق الهدايا، وعدّادا الجوائز، وزمزم |
| `src/scenes/S5Cta.tsx` | المشهد الخامس: الشعار والمتجران والرابط ورمز QR والشروط |
| `src/components/` | الهاتف والكعبة والصندوق وشاشات التطبيق والنصوص المتحركة |
| `scripts/make_audio.py` | يولّد الموسيقى والمؤثرات من الصفر، فلا حقوق عليها |

كلُّ مشهدٍ مستقلّ في ملفّه ويبدأ عدّه من الإطار صفر، فيُعدَّل توقيته من `SCENES` في `theme.ts` وحده.

## أصولٌ مؤقّتة يجب استبدالها قبل النشر

- **الشعار**: `src/components/NusukLogo.tsx` رسمٌ متّجهٌ مؤقّت مأخوذ عن شعار الملصق المرجعيّ، فاستبدله بملف SVG الرسميّ من دليل هوية نُسك.
- **شاشات التطبيق**: أُعيد بناؤها متّجهةً من لقطات الشاشة المرجعيّة، ويمكن استبدالها بتسجيلات شاشة حقيقية.
- **شارتا المتجرين**: تقريبيّتان، فاستعمل الشارات الرسمية من Apple وGoogle عند النشر.
- **التعليق الصوتي**: انظر `VOICEOVER.md`.
