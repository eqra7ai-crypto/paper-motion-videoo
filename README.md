# Pip's Little Paper World

<div dir="rtl">

فيلمٌ قصيرٌ (27 ثانية، ‎1920×1080‎، ‏30 إطارًا في الثانية) بأسلوب قصاصات الورق المصنوعة يدويًّا، يستيقظ فيه «پِپ» على تلّةٍ ورقيّةٍ مطويّة، ثمّ يقفز عبر المرج ويعثر على بذرة فيزرعها ويسقيها، فتنمو زهرةٌ بحركةٍ مستوحاةٍ من التحريك بالإيقاف (stop-motion)، وتتحوّل الأرض حولها إلى حديقةٍ ورقيّة، ثمّ ينتهي المشهد بجلوس پِپ بجوار الزهرة داخل إطارٍ ورقيٍّ دائريّ.

## الناتج

- الفيديو: ‎`out/pips-little-paper-world.mp4`‎ ‏(H.264 ‏+ AAC، ‏1920×1080، ‏30fps، ‏27 ثانية).
- الموسيقى والمؤثّرات الصوتيّة تُولَّد إجرائيًّا في ‎`out/soundtrack.wav`‎.

## البنية

| الملفّ | الوظيفة |
|---|---|
| ‎`index.html`‎ | مشغّل المعاينة التفاعليّ، وهو أيضًا الصفحة التي يُصيَّر منها الفيديو (‎`?render`‎) |
| ‎`src/timeline.js`‎ | الخطّ الزمنيّ المشترك بين الصورة والصوت: القفزات، والقطرات، والحديقة، والإشارات الصوتيّة |
| ‎`src/paper.js`‎ | دوالّ التسهيل والإطارات المفتاحيّة، والمسارات العضويّة المقصوصة، وملمس ألياف الورق |
| ‎`src/pip.js`‎ | هيكل الشخصيّة (Squash & Stretch، والرمش، والنظر، والذراعان، وحمل الأشياء) |
| ‎`src/scene.js`‎ | العالم بطبقاته وحركة الكاميرا والقصّة كاملةً بوصفها دالّةً خالصةً للزمن ‎`render(t)`‎ |
| ‎`scripts/render.mjs`‎ | يلتقط كلّ إطارٍ عبر Playwright/Chromium، ثمّ يمرّره إلى ffmpeg |
| ‎`scripts/audio.mjs`‎ | يركّب موسيقى كاليمبا هادئة ومؤثّرات ورقيّة بلا أيّ ملفّاتٍ خارجيّة |

لا يعتمد المشهد على أيّ صورٍ جاهزة، إذ تُرسَم كلّ الأشكال إجرائيًّا بـSVG مع تدرّجاتٍ وظلالٍ ورقيّةٍ ناعمةٍ وملمسٍ مولَّد، كما أنّ الحركة حتميّةٌ تمامًا، فيطابق كلّ إطارٍ في المعاينة نظيره في الفيديو.

## إعادة التصيير

المتطلّبات: Node.js ‏18 فما فوق، وffmpeg (مع libx264)، وChromium الخاصّ بـPlaywright.

</div>

```bash
npm install                 # playwright فقط
npx playwright install chromium   # تخطَّ هذه الخطوة إن كان Chromium مثبّتًا مسبقًا
npm run render              # يولّد الصوت ثمّ يصيّر الفيديو إلى out/pips-little-paper-world.mp4
```

<div dir="rtl">

خياراتٌ إضافيّة:

</div>

```bash
node scripts/audio.mjs                                  # الصوت وحده
node scripts/render.mjs --workers 4                     # عدد صفحات المتصفّح المتوازية
node scripts/render.mjs --from 12 --to 16 --out out/clip.mp4   # مقطعٌ جزئيّ
node scripts/render.mjs --stills 2,9.15,19.7            # لقطاتٌ ثابتة في out/stills/
npm run preview                                         # ثمّ افتح http://localhost:8080
```
